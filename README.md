# SpendWise

## Project Description

SpendWise is a budgeting app that lets users set a monthly budget, add and
delete expenses, and see the dashboard update immediately. It shows spending
by category and gives feedback on whether the user is on track, close to the
limit or over budget.

## Technologies Used

- HTML5
- CSS3 (Grid, Flexbox, custom properties, media queries, dark theme)
- JavaScript (arrays, loops, conditionals, DOM manipulation, events)
- Git and GitHub
- Netlify

## Deployment Process Summary

1. Pushed the project to a public GitHub repository.
2. Created a Netlify account and signed in with GitHub.
3. Imported the SpendWise repository into Netlify.
4. Left the build command empty and the publish directory as the repository
   root, because the site is plain HTML, CSS and JavaScript.
5. Deployed the site and tested it at the live URL.
6. Changed the logo color, pushed it to GitHub, and confirmed
   Netlify rebuilt and published the change automatically.
